# Arabic Level Test — Final v4

نسخة نهائية جاهزة للرفع على GitHub Pages.

## الملفات
- `index.html` — الصفحة الرئيسية وإدخال اسم الطالب.
- `test.html` — الاختبار التفاعلي.
- `result.html` — التقرير التشخيصي.
- `css/style.css` — التصميم المتجاوب.
- `js/questions.js` — بنك 40 سؤالًا.
- `js/quiz.js` — التنقل، المؤقت، المراجعة والحفظ.
- `js/scoring.js` — محرك التشخيص وتحديد المستوى.
- `js/result.js` — بناء التقرير.

## خصائص النسخة
- 40 سؤالًا / 4 اختيارات.
- 25 دقيقة.
- 6 مهارات: النحو، الصرف، التحويل، اللغة والتراكيب، الأساليب والبلاغة، فهم واستيعاب.
- توزيع المهارات: 10 نحو، 7 صرف، 6 تحويل، 6 لغة وتراكيب، 5 بلاغة، 6 فهم.
- 6 درجات صعوبة.
- تحليل المهارات ومستويات الصعوبة.
- تقرير قابل للطباعة.
- يعمل بدون Node أو مكتبات خارجية.
- مناسب لـ GitHub Pages.

## التشغيل
افتح `index.html` محليًا، أو ارفع الملفات كما هي إلى مستودع GitHub ثم فعّل GitHub Pages.
